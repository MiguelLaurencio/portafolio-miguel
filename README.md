# Portafolio de Miguel Laurencio

Portafolio bilingüe (español e inglés) hecho con HTML, CSS y JavaScript puro.

## Estructura
- `index.html`: contenido en español (el inglés vive en `script.js`, objeto `EN`).
- `styles.css`: estilos.
- `script.js`: cambio de idioma, menú móvil, enlace activo y foto de respaldo.
- `images/sdad.jpg`: tu foto (si no existe, se muestran las iniciales).
- `cv/CVmigue.pdf`: tu CV para el botón de descarga.

## Probar
Abre la carpeta en VS Code y usa Live Server.
